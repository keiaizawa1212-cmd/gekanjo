# 月別御勘定書

事務所の「発生分請求書発行リスト」を置き換える業務アプリです。

- `index.html` … アプリ本体（1ファイルで動きます）
- `version.json` … バージョン表示と更新案内用

得意先マスタはこのリポジトリに入れていません。初回にアプリの「通知設定 → 復元」から読み込むか、
Firebase を設定するとログイン後に自動で読み込まれます。

## 公開

GitHub Pages で `main` ブランチのルートを公開しています。

## 設定

`index.html` の `FIREBASE_CONFIG` に Firebase の設定値を入れると、ログインと複数端末の共有保存が有効になります。
空のままでは、各端末のブラウザ内（localStorage）に保存されます。

Chatwork への自動投稿は、`通知設定` に受け口の URL を入れたときだけ動きます。
